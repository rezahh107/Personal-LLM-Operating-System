# Incubator

Purpose: preserve early-stage thoughts before they become repository-safe artifacts.

This directory is for material that may be useful later but is not yet accepted memory, project policy, protocol, verified claim, implementation plan, or validated design.

## Contents

- `raw-ideas/` — raw user ideas, sudden thoughts, brainstorming notes, and model-captured idea records extracted from conversation.

## Boundary

Incubator content preserves possibility, not truth.

Files in this directory may be useful input to `protocols/IDEA_MATURATION_PIPELINE.md`, but they do not bypass claim lifecycle, verification, provenance, or memory promotion gates.

## Promotion rule

An incubated item may move forward only after it is reframed, challenged, classified, and either promoted, quarantined, rejected, or archived through the repository's existing governance protocols.
