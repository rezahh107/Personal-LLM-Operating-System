# Escalation Protocol

If technical certainty is missing, do not ask the user to act as an expert verifier.

Use one of these escalation paths:

- deterministic tool or scanner
- validator rule
- fixture or eval
- CI check
- second-model critique
- stronger-model review
- current-source/web verification
- quarantine
- explicit `not_verifiable` status
- user coordination decision for goals, direction, or approval

User approval is not technical proof. It is a coordination decision.
