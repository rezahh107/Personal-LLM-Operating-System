# Memory Promotion Rules

Before adding model-generated content to permanent docs, ask:

- Is this a user preference?
- Is this an accepted fact?
- Is this a candidate claim?
- Does it need evidence?
- Could downstream models misuse it?
- Should it be quarantined instead?
- Is there a schema or validator for this if it is critical?

Permanent memory should be short, stable, scoped, source-aware, and downstream-safe.

Temporary reasoning should not become permanent memory.
