# Audit Domain Adapter

Status: placeholder foundation

Audit is a domain adapter, not the parent architecture.

Initial rules:

- Do not use audit language as assurance.
- Separate tool-backed findings from model observations.
- Do not claim security, compliance, production readiness, or complete coverage.
- Preserve checked / unchecked / unknown areas.
- No repair starts from an unverified claim.

Future work should define scanner output schemas, report trust calibration, and evidence-gated merge review protocols.
