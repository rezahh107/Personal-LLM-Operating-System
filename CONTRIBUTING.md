# Contributing

This is a private personal operating repository. Contributions are currently expected to come from the owner and authorized model-assisted sessions.

## Change rules

- Prefer branches and pull requests after the initial repository bootstrap.
- Do not add unstable model output directly to accepted docs.
- Use the Idea Maturation Pipeline for strategic changes.
- Add or update schemas/validators when a critical behavior rule becomes enforceable.
- Preserve uncertainty in handoffs and reports.
